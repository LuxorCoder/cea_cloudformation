CEA cloudformation repository

Hands-on AWS infrastructure project covering:
- VPC networking
- Public and private subnets
- Route tables
- Internet Gateway
- Bastion Host
- EC2
- Security Groups
- IAM
- CloudFormation
- S3
- Load Balancing
- Auto Scaling
